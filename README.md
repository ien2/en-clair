# Jiminy

La petite voix numérique de la famille.

Un outil pour les parents : ce que chaque enfant utilise (appareils, comptes, applications, sites), les réglages à faire, des conseils par âge et par situation, une charte familiale et un espace pour chaque enfant.

- Tout fonctionne dans le navigateur. Aucune donnée n'est envoyée ni stockée sur un serveur.
- Les informations restent sur l'appareil du parent, qui peut télécharger une sauvegarde (fichier JSON) et la reprendre ailleurs.
- Le site est volontairement non référencé.

## Fichiers

- `index.html` : l'outil
- `icones.js` : icônes affichées par défaut
- `mentions-legales.html` : mentions légales et confidentialité

Les noms et logos des applications appartiennent à leurs propriétaires respectifs et servent uniquement à les identifier. Contact : contact@intersectionsholding.com
